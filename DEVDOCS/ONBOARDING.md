## 1. The checklist

- [ ] **Accept the repo invite.**
  <https://github.com/VeneratedApotheosis/CS35L-Project-1/invitations>

- [ ] **Accept the project invite.** Then open the
  [project board](https://github.com/users/VeneratedApotheosis/projects/2)
  and check that it loads. If you get a 404, you don't have access yet.

- [ ] **Install git.** <https://git-scm.com/downloads>

- [ ] **(Optional) Install the GitHub CLI (`gh`)** and log in:

  ```bash
  gh auth login
  ```

  The command line is optional. VS Code with the GitHub Pull Requests
  extension, Xcode, GitHub Desktop, or any other method works fine.

- [ ] **Clone the repo.**

  ```bash
  git clone https://github.com/VeneratedApotheosis/CS35L-Project-1.git
  cd CS35L-Project-1
  ```

- [ ] **Read the docs:**
  -  Go back to developer.md for more information
  - `ISSUES_AND_PROJECTS.md`
  - `COMMITS.md`
  - `CONTRIBUTOR.md` (last)
